# 📊 Exploratory Data Analysis — Retail Sales

## 📌 Project Overview

This project was completed as part of the Oasis Infobyte Data Analytics Internship.

The objective was to perform an Exploratory Data Analysis (EDA) on a retail sales dataset to uncover meaningful patterns, trends, and insights that can support data-driven decision-making.

# 🎯 Objectives

Understand the structure and characteristics of the retail sales dataset.
Perform data cleaning and preparation.
Explore sales trends and customer purchasing patterns.
Identify important relationships and patterns within the data.
Create meaningful visualizations to communicate key findings.
Generate actionable insights from the analysis.

# 🛠️ Tools & Technologies

Python
Pandas — data manipulation and analysis
NumPy — numerical operations
Matplotlib — data visualization
Seaborn — statistical visualization
Jupyter Notebook — analysis environment

# 🔍 Analysis Performed
The analysis involved:

Loading and inspecting the dataset.
Checking data types and data quality.
Identifying and handling missing values.
Exploring numerical and categorical variables.
Performing descriptive statistical analysis.
Investigating relationships and patterns within the dataset.
Creating visualizations to communicate findings.
Summarizing the key insights obtained from the analysis.

# 📈 Key Insights

The analysis explored retail sales patterns across the available variables and used visualizations to identify notable trends and relationships.
The complete analysis, visualizations, and findings are available in the Jupyter Notebook included in this repository.
